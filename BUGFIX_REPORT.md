## Описание проблемы

### Проблема 1: Потеря памяти ИИ между сессиями
Каждый новый чат создавал и заменял файл persona, что приводило к потере информации о пользователе. Система памяти не работала эффективно — данные о имени, возрасте и других фактах теряются при новой сессии.

**Симптомы:**
- Файл persona перезаписывается с каждым сообщением
- Информация о пользователе не сохраняется между сессиями
- Ассистент забывает данные о пользователе

### Проблема 2: Ошибка 302 при загрузке файла
При попытке прочитать файл persona с Яндекс.Диска возникала ошибка 302 (Redirect), потому что клиент не следовал редиректам.

**Симптомы:**
```
PERSONA DOWNLOAD: ошибка 302
```

## Исправленные проблемы

### 1️⃣ Добавлена гарантия существования файла

**Новая функция `ensure_persona_exists()`:**
- Проверяет существует ли файл persona на диске
- Если файл не существует — создает его один раз (пустой)
- Гарантирует, что файл создается только один раз, не перезаписывается

**Код:**
```python
async def ensure_persona_exists(token: str) -> bool:
    """Проверяем существует ли файл persona, если нет - создаем пустой"""
    headers = {"Authorization": f"OAuth {token}"}
    try:
        async with httpx.AsyncClient() as client:
            resp = await client.get(
                "https://cloud-api.yandex.net/v1/disk/resources",
                headers=headers,
                params={"path": PERSONA_PATH}
            )
        
        if resp.status_code == 200:
            print(f"PERSONA: файл уже существует на диске")
            return True
        
        if resp.status_code == 404:
            print(f"PERSONA: файл не найден, создаем новый...")
            return await write_persona(token, {}, existing=None)
        
        return False
    except Exception as e:
        print(f"PERSONA ENSURE ERROR: {e}")
        return False
```

### 2️⃣ Исправлена ошибка 302 при загрузке

**Решение:** Добавлен параметр `follow_redirects=True` в `httpx.AsyncClient()`

**Было:**
```python
async with httpx.AsyncClient() as client:
    resp2 = await client.get(download_url)
```

**Стало:**
```python
async with httpx.AsyncClient(follow_redirects=True) as client:
    resp2 = await client.get(download_url, timeout=10.0)
```

### 4️⃣ Улучшена обработка ошибок и логирование

**Добавлено:**

- Проверка наличия `download_url` и `upload_url` перед использованием

### 5️⃣ Безопасность данных при сохранении

**Защита:**
- При ошибке сохранения — система НЕ теряет старые данные
- При любой ошибке GPT — возвращаются существующие факты без изменений
- Проверка целостности: если данных меньше чем было — запись блокируется

**Логика:**
```python
if existing and len(facts) < len(existing) and existing:
    print(f"PERSONA WRITE BLOCKED: попытка записать {len(facts)} фактов вместо {len(existing)}")
    return False
```

## Изменения в webhook обработчике

**Было:**
```python
if session_id not in sessions:
    persona = await read_persona(user_token)
    sessions[session_id] = {"persona": persona, "files": []}
```

**Стало:**
```python
if session_id not in sessions:
    # При первом обращении - убеждаемся что файл существует
    await ensure_persona_exists(user_token)
    # Теперь читаем файл (он гарантированно существует)
    persona = await read_persona(user_token)
    sessions[session_id] = {"persona": persona, "files": []}
```
